۱) احراز هویت (Auth)

POST /auth/register Public

ثبت‌نام هنرجو. بعد از ثبت، توکن‌ها برمی‌گردد و کاربر در همه دوره‌های فعال enroll می‌شود.

Body
{
  "firstName": "آوا",
  "lastName": "محمدی",
  "password": "etudepiano123",
  "confirmPassword": "etudepiano123"
}
Response (خلاصه)
{
  "accessToken": "...",
  "refreshToken": "...",
  "tokenType": "Bearer",
  "expiresIn": "15m",
  "user": { "id": "...", "displayName": "آوا محمدی", "studentCode": "ET-..." },
  "session": { "firstName": "آوا", "lastName": "محمدی", "displayName": "آوا محمدی", "loggedInAt": "..." }
}
POST /auth/login Public

ورود هنرجو با نام و نام‌خانوادگی فارسی + رمز عبور.

Body
{
  "firstName": "آوا",
  "lastName": "محمدی",
  "password": "etudepiano123"
}
POST /auth/admin/login Public

ورود ادمین با ایمیل و رمز.

Body
{
  "email": "admin@etude.academy",
  "password": "AdminEtude!2026"
}
POST /auth/register/student Admin Bearer

ثبت هنرجو توسط ادمین (اختیاری: studentCode).

{
  "firstName": "سارا",
  "lastName": "احمدی",
  "password": "SecretPass1",
  "studentCode": "ET-1405-ABCD"
}
POST /auth/refresh Public

گرفتن Access Token جدید با Refresh Token.

{ "refreshToken": "..." }
POST /auth/logout Bearer

خروج و ابطال Refresh Token.

{ "refreshToken": "..." }
GET /auth/me Bearer

اطلاعات کاربر و نشست جاری.

۲) داشبورد و دوره‌ها (Catalog)

همه این Endpointها به Authorization: Bearer <accessToken> نیاز دارند.
GET /dashboard Bearer

داده تجمیعی پیشخوان: لیست دوره‌ها، آمار، جلسه بعدی، تمرین‌ها، جلسه جاری.

GET /courses Bearer

فهرست دوره‌های ثبت‌شده هنرجو. پشتیبانی از page, limit, search.

GET /courses/:id Bearer

جزئیات یک دوره (slug یا uuid). مثال: /courses/theory-basics

GET /courses/:id/certificate Bearer

وضعیت آماده‌بودن مدرک پایان دوره.

{ "courseId": "theory-basics", "ready": false, "downloadUrl": null }
GET /sessions?courseId=theory-basics Bearer

لیست جلسات یک دوره. بدون courseId دوره اصلی (اولین دوره فعال) استفاده می‌شود.

GET /sessions/:id Bearer

جزئیات جلسه. id می‌تواند شماره جلسه (1) یا UUID باشد. Query اختیاری: courseId

GET /sessions/:id/slides Bearer

اسلایدهای جلسه — فقط اگر وضعیت جلسه available باشد.

GET /schedule?courseId=... Bearer

برنامه کلاس‌ها + شبکه پیشرفت جلسات دوره.

GET /profile Bearer

پروفایل هنرجو، دوره‌ها و دستاوردها.

GET /masterclass Bearer

Legacy: برمی‌گرداند همان دوره اصلی (primaryCourse) برای سازگاری با کلاینت قدیمی.

GET /masterclass/certificate Bearer

Legacy: وضعیت گواهی دوره اصلی.

۳) مدیریت کاربران (فقط ادمین)

همه این‌ها نیاز به توکن ادمین دارند. اول با POST /auth/admin/login وارد شو.
GET /users?page=1&limit=20&role=STUDENT&search=آوا Admin Bearer

لیست کاربران ثبت‌نام‌شده. فیلترها: role, isActive, search, sort.

GET /users/stats Admin Bearer

آمار: total / students / admins / active / inactive

GET /users/:id Admin Bearer

جزئیات کاربر + enrollments + achievements

PATCH /users/:id Admin Bearer

ویرایش نام، ایمیل، سطح، کد هنرجو، isActive

POST /users/:id/reset-password Admin Bearer

ریست رمز و باطل کردن همه refresh tokenها

{ "password": "NewPass123!" }
POST /users/:id/activate | /users/:id/deactivate Admin Bearer

فعال / غیرفعال کردن حساب

POST /users/:id/enrollments Admin Bearer

ثبت کاربر در دوره

{ "courseId": "theory-basics" }
